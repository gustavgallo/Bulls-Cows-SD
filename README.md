<div align="center">

</div>

## 📖 Overview
This project implements the classic Bulls & Cows game on an FPGA board. Players must guess a 4-digit secret number, receiving feedback on:
- 🐂 Bulls: Correct digit in the correct position
- 🐄 Cows: Correct digit but in the wrong position

## 🛠 Hardware & Software Requirements
**Hardware**
- ✅ FPGA Board: Nexys-A7

**Software**
- 🖥 AMD Vivado (for synthesis & implementation)
